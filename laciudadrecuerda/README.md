# La Ciudad Recuerda — Kit de prompts (GPT Image)

Prompts reutilizables para generar la secuencia de **4 imágenes** del formato de [@laciudadrecuerda](https://www.instagram.com/laciudadrecuerda/) con GPT Image (ChatGPT).

## Flujo rápido

1. Abre ChatGPT con **GPT Image**.
2. Copia un prompt completo de [`historias/`](historias/) y pégalo.
3. Pide las **4 imágenes en la misma conversación** (mejor coherencia de persona y entorno).
4. Descarga las verticales y súbelas a Instagram.

Para una historia nueva: copia [`plantilla.md`](plantilla.md), sustituye `[PERSONA]`, `[SITUACION]` y `[ENTORNO]`, y pégalo.

## Si la persona cambia entre fotos

1. Usa la **Imagen 1** como referencia.
2. Pide regenerar 2, 3 y 4 manteniendo el mismo rostro, ropa, edad y entorno.
3. Recuerda: en la Imagen 3 solo se ve el **reverso blanco** de la foto impresa.

## Formato Instagram

Exporta vertical. Preferible **4:5** (retrato feed) o **9:16** (stories/reels). Sin textos, marcos ni overlays en la imagen.
